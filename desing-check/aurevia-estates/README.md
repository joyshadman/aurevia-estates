# Aurevia Estates — static UI mockup

Open `index.html` in a browser (internet connection needed for Tailwind CDN, Google Fonts and Unsplash photos).

| Page | File |
|---|---|
| Homepage | index.html |
| Property discovery | properties.html |
| Property details | property.html |
| AI assistant (mock chat, EN/বাংলা toggle, booking confirmation) | assistant.html |
| About & contact | about.html |
| Admin dashboard | admin.html |

- Styling: Tailwind Play CDN 3.4.17 + shared theme in `assets/js/tailwind.config.js` (brand colours `canvas`, `burgundy`, `plum`, `charcoal`; fonts Playfair Display / Inter / Hind Siliguri).
- `assets/js/ui.js`: visual-only interactions (mobile menu, favourite hearts, grid/list toggle, gallery thumbnails, mock form → confirmation, language toggle).
- All data is sample content for Sylhet; nothing is connected to a backend or AI model.
